# 2026-11-07 · 中英双语切换（i18n）

## 需求
在既有 HabitatQuest 教师工作台原型上增加中英双语切换，保持原有架构、视觉与 GSAP 转场不变。

## 技术方案（不引入新依赖）
- 自研 Context i18n：`src/i18n/index.tsx` 提供 `I18nProvider` / `useI18n()`，暴露 `locale`、`isEn`、`setLocale`、`toggleLocale`、`t(key, params)`。
- 字典 `src/i18n/dict.ts`：`zh` 为唯一键来源（as const），`DictKey = keyof typeof zh`；`en: Record<DictKey, string>` 保证漏译在编译期报错。`t()` 用 `/\{(\w+)\}/g` 做插值。
- 持久化 `localStorage['hq-locale']`；`index.html` 内联脚本提前设置 `lang` / `data-locale` / title / description，避免首屏闪中文；Provider 的 effect 同步 `document.documentElement.lang`、title、meta。
- `src/i18n/labels.ts` 为实体/数据标签层：`habitatLabel`、`gameLabel`、`gameDesc`、`statusLabel`、`badgeLabel`、`classLabel`、`classShortLabel`、`rangeLabel`、`studentName`、`animalLabel`。

## 关键约定（后续维护务必遵守）
- **中文字符串继续作为数据主键**：班级名 `'三年级 A 班'`、学生中文名（头像哈希 / 搜索匹配基于它）、动物中文名（错误热点逻辑基于它）。英文只作展示字段，不要改写数据键。
- `randomName(rand)` 仍消耗同样两次 PRNG 调用，只是返回 `{ cn, en }`，保证 `SEED = 20260515` 的固定种子数据不漂移。
- `AttentionItem` 的 `reason: string` 改为结构化 `reasonKey` / `days` / `habitat` / `accuracy`，数据层不含 UI 文案，UI 侧用 `reasonText()` 按语言拼装。
- `RealtimeEvent` 去掉 `gameCn`，改为 `studentNameEn`；游戏名统一走 `gameLabel(id, locale)`。
- `src/lib/format.ts` 的 `relativeTime` / `durationSec` / `shortDate` / `weekdayLabel` / `num` 均增加可选 `locale` 参数，默认 `'zh'` 保持向后兼容。
- `MistakeBars.tsx` 有意保留「另一语言小字」：中文模式显示英文副名，英文模式显示中文副名，作为双语教育提示（如 `Penguin 企鹅`）。这是设计决策，不是漏译。
- 转场选择器全为 data-attribute（如 `[data-login-submit]` / `[data-dashboard]`），不依赖文案，双语化不影响 GSAP 动画。

## 组件接入
登录页、TopBar、DashboardPage、KpiCard、StudentTable、StudentDrawer、AttentionPanel、RealtimeToast、ThemeToggle、4 个图表组件（TrendArea / HabitatRadar / ScoreHistogram / MistakeBars）全部改为 `t()` + label helpers。
`src/components/LanguageToggle.tsx` 为 `中 / EN` 分段控件，登录页用 `compact`，工作台顶栏用默认尺寸；带 `aria-pressed` / `aria-label` / `title`。
`main.tsx` 用 `<I18nProvider>` 包裹 `<App />`。

## 修复
- 英文模式 `Needs Attention` 长原因文字挤压 `Assign` 按钮：内层 button 缺宽度约束导致 `truncate` 失效。改为 `block w-full min-w-0 text-left` + `title={reason}`，原因文本用 `line-clamp-2`（Tailwind v4 已生成该工具类），中英两态均完整可读且不重叠。
- 同时消掉 `noUnusedLocals` 隐患（此前引入的 `reason` 局部变量未使用）。
